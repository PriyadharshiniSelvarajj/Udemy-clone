# Udemy-clone
This project is a simple Udemy-inspired website built using HTML and CSS. It was created as part of my Full Stack Development learning journey to practice front-end web development fundamentals and improve my understanding of webpage structure, styling, and layout design.

## Features - 
Responsive homepage layout - Navigation bar and search section - Course categories and course cards - Promotional banner section - Footer section - Clean and modern UI inspired by Udemy

## Technologies Used -
HTML5 - CSS3

## What I Learned - 
Structuring webpages with semantic HTML - Styling layouts using CSS - Working with flexbox/grid concepts - Creating reusable UI components - Improving visual design and spacing

## Purpose 
The goal of this project was to recreate the look and feel of an online learning platform while strengthening my front-end development skills through hands-on practice.

## Future Improvements - 
Add JavaScript for interactivity - Implement responsive design for all screen sizes - Add course filtering and search functionality - Integrate backend functionality in future versions

This project demonstrates my ability to build and style multi-section web pages using core front-end technologies.
